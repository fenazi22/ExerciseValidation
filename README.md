# ExerciseValidation

A Java practice repository focused on validation logic.

## Project Overview

This project is used to practice how to validate input values and apply simple rules before processing data in a Java application.

## Main Topics

- Java fundamentals
- Input validation
- Conditional logic
- Methods
- Error messages
- Clean code structure

## Example Use Cases

- Check required fields.
- Validate numbers and text values.
- Apply simple business rules.
- Return clear messages when input is not valid.

## Learning Goals

- Understand validation flow.
- Write clear IF conditions.
- Keep validation logic simple.
- Improve Java problem-solving skills.
